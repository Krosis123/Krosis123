# Usman Yahya

I'm a computer science student interested in low-level systems, computer architecture, and AI. My recent projects use FPGAs to simulate gene networks and process audio samples.

## Selected projects

- [FPGA Accelerator](https://github.com/Krosis123/FPGA-Accelerator) runs Boolean gene networks on an FPGA and measures the period of the cycle reached from a given starting state.
- [FPGA Audio](https://github.com/Krosis123/audio_proj) computes signal energy and counts zero crossings in blocks of audio samples. A Python script checks the results over UART.
- **Memory Latency Benchmark** uses pointer chasing to study cache and TLB behavior.
